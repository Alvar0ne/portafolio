Migración y Modernización Empresarial VMware → AWS

Diseño e implementación End-to-End de la migración de una plataforma e-commerce desde VMware hacia AWS, utilizando Terraform como Infrastructure as Code. Implementé una arquitectura Multi-AZ y altamente disponible con VPC, subnets públicas/privadas, ALB, EC2 Auto Scaling, Docker/ECR y RDS PostgreSQL. Incorporé DMS para migración de datos, CloudWatch/SNS para observabilidad, EventBridge + SQS + Lambda para procesamiento event-driven, S3 + Glue + Athena para analítica serverless y CI/CD con GitHub Actions + OIDC.

AWSTerraformDockerPostgreSQLNext.jsGitHub ActionsEventBridgeLambdaSQSS3GlueAthenaCloudWatch
Estado: Proyecto finalizado
Ver en GitHub

Detalles del proyecto

Objetivo

Migrar y modernizar una plataforma e-commerce desde VMware hacia AWS, con infraestructura definida mediante Terraform.

Arquitectura

Arquitectura Multi-AZ con VPC, subnets públicas y privadas, ALB, EC2 Auto Scaling, contenedores Docker/ECR y RDS PostgreSQL.

Datos

Migración de datos con DMS y analítica serverless mediante S3, Glue y Athena.

Resultado

Proyecto finalizado: migración y modernización End-to-End de la plataforma e-commerce hacia AWS.
